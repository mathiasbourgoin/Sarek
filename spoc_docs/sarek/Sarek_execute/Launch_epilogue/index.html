Module Sarek_execute.Launch_epilogue

Epilogue fusion in the launch window (specs/epilogue-fusion.md).

When an element-wise launch C arrives, it is merged into a pending launch P that writes the one vector I it consumes, if all of the following hold. The merged launch replaces P in its group and can itself host a further epilogue or join a horizontal group. The rewrite is Fusion_epilogue.

Conditions (vectors compared by identity, on one device).

  • The backend runs epilogues for these kernels (decide_pair): not switched off (set_backend_enabled), and exact (HIP, Metal) or granted Cross_kernel_contraction for both P and C (CUDA, OpenCL, Vulkan).
  • C has the consumer shape (Fusion_epilogue.consumer). C is 1-D with no dynamic shared memory.
  • Among the vectors P writes, C reads exactly one, I. C reads I only at its own index. P does not read I, and P binds I to exactly one parameter.
  • C writes nothing P accesses, except I itself.
  • C conflicts with no other launch of P's group, and with no launch of a later group.
  • Coverage (for these dimensions and scalar values): P stores each element of I at most once, at a non-negative index, and every element C writes is one that P stores. Proven by Coverage_affine when the indices are affine, else by enumerating both launches with Index_slice, within max_enumerated threads.

The coverage verdict is cached by (P, the producer array, C, their dimensions, the values of the scalars the evaluation read).

Whether the epilogue of consumer may be merged into producer on backend: the backend is not switched off or inexact, and Sarek_policy.decide allows Sarek_policy.optimisation.Epilogue_fusion for the meet of both kernels' budgets.

val available : string -> bool

Whether fusion can run on backend under the process grants alone: not switched off, exact, and allowed by Sarek_policy.decide for the process budget (HIP and Metal; the others once Cross_kernel_contraction is granted at process scope). Kernel-scoped grants are not seen: the decision per pair is decide_pair.

The window's epilogue hook (install).

val install : 'a LW.t -> unit

Enable epilogue fusion in w (on the backends enabled allows). An unexpected exception while deciding means no merge: the launch then takes the ordinary path.

val clear : unit -> unit

Forget every cached consumer shape, coverage verdict and merged kernel.
