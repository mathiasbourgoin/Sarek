Module Sarek_execute.Index_bitset

A set of array indices in [0, capacity), one bit each, grown on demand: the store sets of the epilogue coverage enumeration (Launch_epilogue), without hashing or polymorphic comparison per element.

Largest index + 1 a set accepts (16 MiB of bits).
