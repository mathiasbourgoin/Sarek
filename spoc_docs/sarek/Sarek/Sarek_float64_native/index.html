Operator forms

Declared by the stdlib so that let open Float64 in shadows the float32 operators inside a kernel. Only reachable here when written as a qualified call (Float64.( +. ) a b); infix syntax is lowered structurally by the PPX (Sarek_parse_helpers) and never becomes an IntrinsicRef.
