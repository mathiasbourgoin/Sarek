Module type Transfer.STREAM

Stream handle - packages backend stream with its operations.

stream_ref is the backend stream wrapped by the backend's own wrap_stream, so any other unpacking of the same backend can recover it (Framework_sig.stream_ref). state is this stream's entry in the keep-alive Ledger.

Streams created by create_stream are BLOCKING by default (they synchronise with the device's legacy default stream); with ~non_blocking:true they are not, and order against other streams only through events. The auto-transfer path stays correct for both: after an async ranged write the vector is Stale_CPU; a blocking stream is waited for by the default stream, a non-blocking one is settled on the host by settle_vector before the implicit read-back or default-stream launch.
