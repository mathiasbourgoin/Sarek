Module Sarek_codegen.Sarek_ir_metal_coopmat

Cooperative matrix (SCoopmat) for the Metal generator, lowered to MSL simdgroup_matrix (specs/coopmat-metal-simdgroup.md).

MSL offers exactly three instantiations, all 8x8 (half, float, bfloat; docs/design/f16-relaxed-accuracy.md §7 slice 6, measured on an Apple M4), and no integer one. The lowered configuration is therefore the single one whose numerics were measured and are a closed form: simdgroup_half8x8 x half8x8 + float8x8 -> float8x8, 8x8x8, bit-equal on 65536/65536 elements to "accumulator = C, then add the eight products in index order, all in binary32". Everything else is refused here, at code generation, with the reason.

Layout is the transpose_matrix flag of simdgroup_load / simdgroup_store: with elements_per_row = stride and no transpose, element (r, c) is at ptr + r * stride + c; with it, at ptr + c * stride + r. This is exactly Sarek_coopmat_types.layout.
