Error handling

exception Ptx_codegen_error of string
val fail : string -> 'a

fail msg raises Ptx_codegen_error with msg.

val unsupported : string -> 'a

unsupported what raises Ptx_codegen_error for an unsupported IR construct named what.

val unsupported_elttype : Sarek_ir_types.elttype -> string -> 'a

unsupported_elttype ty what raises Ptx_codegen_error for an element type this emitter cannot represent, at the site named what. Today only TFloat16 reaches it: f16 is deliberately out of scope for the PTX backend in #57 slice 1, because this emitter derives a value's register class from the register NAME's prefix (%f / %fd / %rd), so introducing a %h class requires auditing every such guard first. Shared so the expression emitter, the type mapping and the whole-kernel gate all report it identically — and generic in ty so the next width does not need a second feature-specific export next to fail.

Value bindings

type agg_value =
  1. | ARecord of (string * binding) list
  2. | AVariant of {
    1. vname : string;
    2. tag_reg : string;
    3. ctors : (string * binding list) list;
    }

SROA-decomposed aggregate value: a record is one binding per field (in declaration order, nested records as nested ARecord); a variant is a u32 tag register plus one payload slot list per constructor, ALL constructors in declaration order (a constructor's tag value = its position in ctors). Slots of constructors other than the one a value was built with are freshly-allocated, never-written registers: undefined contents, never read dynamically, present so every value of a variant type has a uniform full shape for leaf-wise copy/mov merging.

and binding =
  1. | Scalar of string
  2. | Agg of agg_value

A variable's PTX value: a single scalar register name, or an aggregate register set.

Register allocator

type arr_space =
  1. | SpaceShared
  2. | SpaceLocal

Non-global state space of an array known to the emitter. Arrays absent from arr_memspaces are global (vector parameters).

type soa_leaf = {
  1. sl_field : string;
  2. sl_type : Sarek_ir_types.elttype;
  3. sl_base : string;
}

One scalar leaf of a Structure-of-Arrays (SoA) custom-vector parameter: the record field it comes from, its scalar type, and the u64 register holding its own device base pointer (each leaf lives in its own contiguous device buffer).

type reg_alloc = {
  1. mutable u32 : int;
  2. mutable u64 : int;
  3. mutable f32 : int;
  4. mutable f64 : int;
  5. mutable pred : int;
  6. mutable label : int;
  7. arr_elt_types : (string, Sarek_ir_types.elttype) Stdlib.Hashtbl.t;
  8. arr_memspaces : (string, arr_space) Stdlib.Hashtbl.t;
  9. arr_soa : (string, soa_leaf list) Stdlib.Hashtbl.t;
    (*

    Custom-vector parameters lowered as Structure-of-Arrays: name -> its scalar leaves in record declaration order. A name present here is SoA; absent means AoS. Empty for every kernel compiled without SoA.

    *)
  10. shared_decls : Stdlib.Buffer.t;
    (*

    .shared declarations discovered while emitting the body; spliced into the kernel prologue by generate.

    *)
  11. local_decls : Stdlib.Buffer.t;
    (*

    .local declarations discovered while emitting the body (SLet-bound per-thread local arrays); spliced into the kernel prologue by generate.

    *)
  12. funcs : (string, Sarek_ir_types.helper_func) Stdlib.Hashtbl.t;
    (*

    Kernel helper functions (kern_funcs), inlined at EApp sites.

    *)
  13. variant_decls : (string, (string * Sarek_ir_types.elttype list) list) Stdlib.Hashtbl.t;
    (*

    Variant type declarations (kern_variants): type name -> constructors in declaration order, needed by EVariant construction (which only carries the type name).

    *)
  14. mutable inline_stack : string list;
    (*

    Helper names currently being inlined — recursion guard.

    *)
  15. inline_budget : (string, int) Stdlib.Hashtbl.t;
    (*

    Remaining recursive-inline depth per helper, seeded from the helper's pragma ["sarek.inline N"] at first entry; consulted (and decremented) only on recursive re-entry. Helpers without the pragma have no entry and recursive re-entry stays an error.

    *)
  16. mutable inline_ret : (binding option * string) list;
    (*

    Per-inline (result binding, end label) for SReturn lowering.

    *)
}

Counter-based register allocator. Each PTX type has an independent counter so that register names stay readable (e.g. %r0, %f0, %rd0).

val make_alloc : unit -> reg_alloc

make_alloc () returns a fresh zeroed allocator.

val arr_space_of : reg_alloc -> string -> arr_space option

arr_space_of alloc name is the registered non-global state space of array name, or None for global arrays (vector parameters).

val is_soa : reg_alloc -> string -> bool

is_soa alloc name is true when vector parameter name was lowered as Structure-of-Arrays (N per-leaf base pointers) rather than packed AoS.

val soa_leaves : reg_alloc -> string -> soa_leaf list

soa_leaves alloc name are the SoA leaves of name in record declaration order. Raises Not_found if name is not SoA (guard with is_soa).

val soa_leaf_of_field : reg_alloc -> string -> string -> soa_leaf option

soa_leaf_of_field alloc name field is the leaf of SoA vector name whose record field is field, or None.

val new_u32 : reg_alloc -> string

Allocate a fresh .u32 register and return its PTX name (%rN).

val new_u64 : reg_alloc -> string

Allocate a fresh .u64 register and return its PTX name (%rdN).

val new_f32 : reg_alloc -> string

Allocate a fresh .f32 register and return its PTX name (%fN).

val new_f64 : reg_alloc -> string

Allocate a fresh .f64 register and return its PTX name (%fdN).

val new_pred : reg_alloc -> string

Allocate a fresh .pred register and return its PTX name (%pN).

val new_label : reg_alloc -> string

Allocate a fresh branch label and return its name (LN).

Type mapping

val ptx_reg_type_of : Sarek_ir_types.elttype -> string

ptx_reg_type_of t returns the PTX register-type string for t (e.g. ".u32", ".f64"). Raises Ptx_codegen_error for TRecord and TVariant.

val new_reg_for_type : reg_alloc -> Sarek_ir_types.elttype -> string

new_reg_for_type alloc t allocates a register appropriate for type t and returns its PTX name.

val binding_of_elttype : reg_alloc -> Sarek_ir_types.elttype -> binding

binding_of_elttype alloc t allocates a fresh binding with the register shape of type t (no instructions emitted; the registers are declared but unwritten). Used to pre-allocate aggregate results (inlined helper returns) and absent-constructor payload slots.

Environment: variable name -> PTX binding

type env = (string, binding) Stdlib.Hashtbl.t

Maps Sarek IR variable names to their PTX bindings.

val make_env : unit -> env

make_env () returns an empty environment.

val env_bind : env -> string -> string -> unit

env_bind env name reg binds name to the scalar register reg, overwriting any previous binding.

val env_bind_binding : env -> string -> binding -> unit

env_bind_binding env name b binds name to b (scalar or aggregate), overwriting any previous binding.

val env_lookup : env -> string -> string

env_lookup env name returns the PTX register for the scalar name. Raises Ptx_codegen_error if name is unbound, or if it is bound to an aggregate (internal error: scalar lookup on aggregate binding).

val env_lookup_binding : env -> string -> binding

env_lookup_binding env name returns the binding for name. Raises Ptx_codegen_error if name is unbound.

val length_param_name : string -> string

length_param_name arr is the name of the implicit length parameter paired with vector/array parameter arr ("sarek_<arr>_length") — the single definition shared by the param emitter and the EArrayLen lookup, matching the convention of Execute.expand_to_run_source_args and the C-family code generators.

Register-class helpers

type reg_class =
  1. | RU32
  2. | RU64
  3. | RF32
  4. | RF64

Register class recovered from a PTX register name prefix (%fdN = f64, %fN = f32, %rdN = u64, %rN = u32).

val reg_class : string -> reg_class

reg_class r is the class of register r, from its name prefix.

val mov_op_of_class : reg_class -> string

mov_op_of_class c is the typed PTX mov opcode for class c.

val new_reg_like : reg_alloc -> string -> string

new_reg_like alloc r allocates a fresh register of r's class.

val mov_scalar : Stdlib.Buffer.t -> dst:string -> src:string -> unit

mov_scalar buf ~dst ~src emits a typed mov of src into dst, typed by dst's register class.

val copy_reg : Stdlib.Buffer.t -> reg_alloc -> string -> string

copy_reg buf alloc r allocates a fresh register of r's class and emits a mov from r into it — for bindings that must not alias the source register (mutable lets, inlined helper parameters).

val copy_binding : Stdlib.Buffer.t -> reg_alloc -> binding -> binding

copy_binding buf alloc b copies every scalar leaf of b into fresh registers (leaf-wise copy_reg), preserving the aggregate shape.

val mov_binding : Stdlib.Buffer.t -> src:binding -> dst:binding -> unit

mov_binding buf ~src ~dst emits leaf-wise typed movs of src's registers into dst's registers. Shapes must be compatible (records matched by field name, variant payload slots by constructor tag); raises Ptx_codegen_error on shape mismatch.
