Module Sarek_vulkan.Vulkan_api_stream

Streams (specs/vulkan-async-launches.md).

A launch is appended to the stream's open command buffer and returns (Vulkan_api_batch.record_dispatch). The buffer is submitted, not waited for, when it holds batch_limit dispatches, when another stream of the device launches, and at any synchronisation point. The host blocks at synchronize, at Vulkan_api_device.drain_pending (host access to device memory, device wait, kernel eviction, device destroy) and when a command buffer is reused. A stream has two command buffers, so one can be recorded while the other runs.

All streams of a device submit to one queue, in launch order, because a launch first submits the open batches of the device's other streams; dispatches are ordered in memory by barriers (Vulkan_api_barrier).
