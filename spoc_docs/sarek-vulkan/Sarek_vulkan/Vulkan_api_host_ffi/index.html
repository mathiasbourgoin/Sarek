Module Sarek_vulkan.Vulkan_api_host_ffi

VK_EXT_external_memory_host: structures and entry points for importing a range of host memory as device memory (specs/vulkan-async-api.md).

The extension's entry point is not exported by the loader, so it is resolved through vkGetDeviceProcAddr, the way Vulkan_bindings resolves the cooperative-matrix query.

type properties_fn = Vulkan_types.vk_device Ctypes.structure Ctypes.ptr -> Unsigned.uint32 -> unit Ctypes.ptr -> host_pointer_properties Ctypes.structure Ctypes.ptr -> Vulkan_types.vk_result
val resolve_properties_fn : Vulkan_types.vk_device Ctypes.structure Ctypes_static.ptr -> properties_fn option

Resolve vkGetMemoryHostPointerPropertiesEXT for device. vkGetDeviceProcAddr returns the entry point of the driver that owns the device (an address inside that driver's library), so the result belongs to this device only: it is kept in the device record and never shared, because a second device may come from another driver. None when the driver does not know the function.

val get_memory_host_pointer_properties : properties_fn -> Vulkan_types.vk_device Ctypes.structure Ctypes.ptr -> unit Ctypes.ptr -> host_pointer_properties Ctypes.structure Ctypes.ptr -> Vulkan_types.vk_result

vkGetMemoryHostPointerPropertiesEXT through fn, the function resolved for device: the memory types host_ptr can be imported as. The device must have been created with extension_name enabled.
