Library spoc.ir

This library exposes the following toplevel modules:

  • Sarek_capability The kernel/backend capability vocabulary (#64, slice 1).
  • Sarek_coopmat Cooperative matrix: the DEVICE-facing half.
  • Sarek_coopmat_types Cooperative-matrix (tensor-core) vocabulary and fragment type.
  • Sarek_f16_policy Single rounding at f32 -> f16 narrowings: an explicit opt-in (specs/f16-narrowing-barrier.md §4).
  • Sarek_ir_affine Affine index forms for access-pattern analysis.
  • Sarek_ir_analysis Sarek_ir_analysis - Analysis functions for GPU kernel IR
  • Sarek_ir_codegen Shared code-generation helpers used across GPU backends (CUDA, OpenCL, Metal, Vulkan/GLSL). Extracted to avoid duplication of identical variant/struct generation logic.
  • Sarek_ir_eval_int Host-side evaluation of uniform int32 expressions (specs/matrix-pattern-rewrite.md).
  • Sarek_ir_layout Sarek_ir_layout - Aligned (C-ABI-compatible) aggregate byte layout for GPU codegen.
  • Sarek_ir_names Names of a kernel that the target language cannot take as written.
  • Sarek_ir_pp Sarek_ir_pp - Pretty printing for GPU kernel IR
  • Sarek_ir_types Sarek_ir_types - Pure type definitions for GPU kernel IR
  • Sarek_matrix_advice What matrix units could do for a recognised GEMM nest.
  • Sarek_matrix_direct The aligned size class of the matrix rewrite (specs/matrix-pattern-dynamic.md).
  • Sarek_matrix_mapping Which outputs a recognised GEMM nest writes (specs/matrix-pattern-rewrite.md, "Preconditions").
  • Sarek_matrix_pattern Recognition of matrix-product (GEMM) loop nests in Sarek IR.
  • Sarek_matrix_pattern_types The vocabulary of Sarek_matrix_pattern: what a recognised GEMM nest and a rejected reduction loop are. Split out so that the index-role analysis (Sarek_matrix_roles) and the recogniser share it; Sarek_matrix_pattern re-exports every type with its equalities.
  • Sarek_matrix_rewrite The rewritten kernel of a GEMM nest (specs/matrix-pattern-rewrite.md).
  • Sarek_matrix_roles Index roles of a GEMM nest (specs/matrix-pattern-advice.md).
  • Sarek_matrix_scheme
  • Sarek_policy One typed store for every precision grant and consent (specs/optimisation-policy.md).
  • Sarek_policy_env
  • Sarek_policy_vocab
  • Sarek_pure_registry
  • Sarek_push_constants Sarek_push_constants - the push-constant block layout of a kernel signature.
  • Sarek_reserved_words Identifiers a generated kernel must not declare, per source language.
  • Sarek_warp Sarek_warp - the one definition of warp shuffle semantics.
