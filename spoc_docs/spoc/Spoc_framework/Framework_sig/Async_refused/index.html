Page-locked host memory of byte_size bytes, returned as a raw address. Released by free_pinned. A backend whose pinned memory belongs to the device (Vulkan: a driver mapping) unmaps it when the device is destroyed; the address is then invalid and only free_pinned may still be called on it.
