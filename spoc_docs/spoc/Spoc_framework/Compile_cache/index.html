Module Spoc_framework.Compile_cache

Shared compile-cache key builder for GPU backend plugins.

Every backend (CUDA, OpenCL, Metal, Vulkan) memoizes compiled kernels keyed by some combination of device identity and kernel source. A source file frequently defines more than one kernel entry point; if the cache key omits the kernel/entry name, the second kernel compiled from a shared source silently resolves to whatever was compiled first under the same key. This module standardizes the key shape so every backend's key includes: device identifier, kernel/entry name, a digest of the source, and canonicalized (sorted) compile options.

This module intentionally does not force backends to use a shared Hashtbl — each backend keeps its own cache table (they differ in what they store: resolved kernel handles, SPIR-V bytes, etc.). The contract this module enforces is only the key *shape*.

val make_key : device:string -> name:string -> source:string -> ?options:(string * string) list -> unit -> string

make_key ~device ~name ~source ?options () builds a standardized cache key string of the form "<device-digest>:<name-digest>:<source-digest>:<options-digest>", where each field is an independent Digest.string MD5 hex digest (32 hex characters, fixed width).

Every component is digested on its own, rather than concatenating the raw strings before hashing, so the ':'-delimited join can never be ambiguous: a fixed-width hex digest cannot itself contain ':', so there is no way for e.g. a device value containing ':' or an options value containing ',' or '=' to shift a byte from one logical field into another and collide with an unrelated (device, name, source, options) tuple.

  • device should be a stable device identifier (e.g. device index, device name, or name+driver-version string — whatever uniquely identifies the compilation target for that backend). Free-form; digested as-is.
  • name is the kernel/entry-point name. Required so that two kernels compiled from the same source never collide under the same key. Digested as-is.
  • source is digested directly.
  • options is an optional association list of compile options (e.g. optimization flags). Entries are sorted by key and joined into a single canonical string before being digested, so option order never affects cache hits. Defaults to [].
