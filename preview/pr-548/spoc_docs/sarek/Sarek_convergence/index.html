How variance is computed. The legacy analysis is the first, cheap pass. The strict analysis is applied to every synchronisation point (warp collectives, whose missed divergence is a silent wrong answer, and barriers, whose missed divergence is a deadlock or undefined behaviour): it also follows the value of an if/match, a helper result that reads the thread, and a mutable assigned under thread-varying control flow (specs/convergence-semantics.md section 3).

val varying : variance -> StringSet.t -> Sarek_typed_ast.texpr -> bool

Check if an expression's value varies per-thread.

Thread-varying (different per thread):

  • thread_idx_x, thread_idx_y, thread_idx_z
  • global_thread_id
  • Expressions derived from above
  • Array accesses with thread-varying index

Uniform (same for all threads in workgroup):

  • Constants and literals
  • block_idx_x/y/z (same for whole block)
  • block_dim_x/y/z, grid_dim_x/y/z
  • Expressions derived only from uniform values

With vi.strict the value of control flow, helper results and mutables assigned in divergence are followed too (see variance).
