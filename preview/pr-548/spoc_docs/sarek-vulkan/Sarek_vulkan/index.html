module Vulkan_api_barrier : sig ... end

Global memory barriers recorded into command buffers. Vulkan orders the start of commands in a queue, not their memory: every producer/consumer pair below needs one. The first scope of a barrier includes every command submitted to the queue before it, so a barrier at the head of a command buffer also orders it after earlier submissions.

module Vulkan_api_release : sig ... end

Deferred release of device buffers, and the allocation retry that depends on it. free runs from Gc.finalise finalisers (Gpu_memory.register_finalizer), which OCaml 5 runs at any allocation point of any domain, even inside batch_lock or queue_lock. A free therefore never submits, records, waits or consumes an error, and never blocks on the batch or queue lock: it queues its release (lock-free) and asks the stream layer to run the queue if the device is idle, which takes the batch lock with try_lock only. The stream registry snapshot it needs uses a short mutex never held across a blocking call; re-entry on it from a finaliser raises, is caught here, and leaves the release queued. A queue that stays non-empty is run at the next drain, idle Stream.synchronize, allocation failure, device destroy, or at the next launch once it is over its bounds (see Vulkan_api_batch.settle).
