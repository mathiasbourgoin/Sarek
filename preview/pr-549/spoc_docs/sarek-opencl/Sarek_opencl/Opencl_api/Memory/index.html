val host_ptr_usable : align_bytes:int -> nativeint -> bool

Whether USE_HOST_PTR over addr is aliased by the runtime rather than privately copied: the address must meet the device's alignment.

val host_ptr_refusal : accept_device:bool -> align_bytes:int -> max_alloc_bytes:Stdlib.Int64.t -> address:nativeint -> byte_size:int -> Spoc_framework.Framework_sig.host_ptr_refusal option

Why a USE_HOST_PTR buffer of byte_size bytes at address is refused, cheapest check first; None when it is accepted. accept_device: the device takes host-pointer buffers (a CPU device). Pure: no device is touched.

val alloc_with_host_ptr : Context.t -> int -> ('a, 'b) Stdlib.Bigarray.kind -> unit Ctypes_static.ptr -> 'c buffer

Allocate buffer over the host pointer (CL_MEM_USE_HOST_PTR). Host access must go through sync_host.

Allocate buffer for custom types with explicit element size in bytes

val aliases_host : 'a buffer -> nativeint -> bool

aliases_host buf addr: buf is a USE_HOST_PTR buffer over addr, so host copies at addr become map/unmap synchronisation.
