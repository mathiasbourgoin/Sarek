The accessors a native kernel calls for a vector argument. A float32 or int32 vector reads and writes its own element type directly (what the typed_value path ends in, Vector.get/Vector.set, without the boxing on the way); every other access, including a read at another type, goes through generic_vec_of_exec_vector.

Contract relied on: an EXEC_VECTOR whose underlying_type_id is Vector.float32_vector_type_id or Vector.int32_vector_type_id has get/set equal to Vector.get/Vector.set on underlying (as Execute.exec_arg_of_vector builds it); the fast accessors read underlying directly.
