Enable from environment variable SAREK_DEBUG=transfer,kernel,... Use "*" or "all" to enable all components. A level (debug, info, warn, error) sets the level; naming a component without a level sets it to debug, so SAREK_DEBUG=kernel prints the kernel component's debug messages. Unknown words are ignored.
