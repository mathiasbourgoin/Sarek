Module Sarek.Sarek_native_fast

Direct element access for the vector parameters of PPX-generated native kernels.

A native kernel reads v.(i) through the accessor object of its argument (v#get i). For a float32 or int32 vector held in a Bigarray, the PPX instead binds the record built here once per work-item and generates

if i >= 0 && i < f.len then Bigarray.Array1.unsafe_get f.ba i else v#get i

The result is the value, the bounds check and the error Vector.get give, with no method call, closure call or boxing on the way.

Exactness contract (what makes this a pure speed-up):

  • the condition uses the vector's length, exactly the test of Vector.get/Vector.set; an index outside it takes the original accessor and so raises the original Invalid_argument with the original message;
  • a vector that is not eligible (other element type, non-Bigarray storage, a Bigarray shorter than length) gets len = 0: every access takes the original accessor, which is the previous behaviour;
  • Vector.ensure_cpu_sync runs once, when the record is built (a launch owns its vector arguments), instead of at every element;
  • a store marks the device copy stale with mark_written, the transition Vector.set performs.
