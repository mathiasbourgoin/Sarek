Module type Framework_sig.ASYNC

Ranged and stream-ordered host<->device transfers, pinned host memory and inter-stream ordering, as one backend provides them. Byte offsets and sizes throughout; bounds are checked by the caller (Spoc_core.Transfer).

~stream:None means synchronous: the call returns once the copy is complete. ~stream:(Some s) enqueues the copy on s and may return before it has run. The raw addresses passed here are NOT GC roots: the caller keeps the memory alive until the stream (or an event recorded after the copy) has completed — Spoc_core.Transfer does this for every Bigarray it passes.

A backend that does not provide an operation raises Sarek_backend_error.Backend_error.Backend_error with a Feature_not_supported payload from it — see Async_refused. It never degrades to a different operation (for instance a synchronous whole-buffer copy).

val alloc_pinned : device -> byte_size:int -> nativeint

Page-locked host memory of byte_size bytes, returned as a raw address. Released by free_pinned. A backend whose pinned memory belongs to the device (Vulkan: a driver mapping) unmaps it when the device is destroyed; the address is then invalid and only free_pinned may still be called on it.
