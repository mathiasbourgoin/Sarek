val memcpy_lazy : (unit Ctypes_static.ptr -> unit Ctypes_static.ptr -> Unsigned.size_t -> unit Ctypes_static.ptr) lazy_t

memcpy from libc for memory transfers, with the OCaml runtime lock released (a large copy would otherwise stop every other domain's minor collections). Both arguments are raw addresses, which the call does not root: the caller keeps the memory behind them allocated until memcpy returns (bigarrays end with ignore (Sys.opaque_identity ba); MTLBuffer contents stays valid while the buffer is retained). See Metal_bindings.msg_void_blocking_lazy.

val mark_fast_math_fallback : unit -> unit

Without the conformant compile options the device compiler runs in Metal's fast-math mode, which may reassociate: a fused epilogue kernel is then no longer guaranteed to equal the unfused pair. Mark Metal inexact so epilogue fusion stays off (docs/fp-contraction-policy.md section 14, Spoc_framework_registry.Fp_exactness).

val probe_conformant_options : unit -> unit

Build the conformant options once at start-up, so a fallback is known before the first launch decides whether to fuse an epilogue.

val force_all : unit -> unit

Force every lazily built FFI stub on the launch, copy and release paths (see Metal_bindings.force_all).
