Module Sarek_vulkan.Vulkan_api_barrier

Global memory barriers recorded into command buffers. Vulkan orders the start of commands in a queue, not their memory: every producer/consumer pair below needs one. The first scope of a barrier includes every command submitted to the queue before it, so a barrier at the head of a command buffer also orders it after earlier submissions.
