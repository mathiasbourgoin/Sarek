val live_allocations : int Stdlib.Atomic.t
val inject_alloc_failure : int Stdlib.ref
val force_unmapped : bool Stdlib.Atomic.t

Test hook: while true, alloc places buffers in DEVICE_LOCAL memory that is never host-mapped, even where HOST_VISIBLE device memory exists, so the staged and imported copy paths of Vulkan_api_transfer can be exercised on a machine whose VRAM is host-visible. Production code never sets it.

val create_transient_pool : Device.t -> Vulkan_types.vk_command_pool

A command pool private to one call: vkCmdXxx, vkBeginCommandBuffer and allocation need external synchronisation of their pool, and these copies run on whichever domain the caller is, so sharing device.command_pool would need a lock held across the recording. A transient pool per call needs none and adds no lock to the order batch_lock -> queue_lock.

val staging_buffers_created : int Stdlib.Atomic.t

Test instrumentation, not an API: staging buffers created since the library was loaded. Lets a test assert that a copy took the staging-free path.

val create_staging_buffer : ?cached:bool -> Device.t -> int -> int -> Vulkan_types.vk_buffer * Unsigned.UInt64.t * unit Ctypes_static.ptr

A mapped HOST_VISIBLE | HOST_COHERENT buffer of size bytes. With ~cached:true the memory is HOST_CACHED when the device has such a type (the host reads it at memory speed; uncached staging memory reads at ~0.25 GB/s), otherwise the plain type.
